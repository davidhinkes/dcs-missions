# Template provenance

These JSON files hold small DCS mission-table records needed by the authoring library: aircraft configurations, baseline weather/mission settings, and Hawkeye/Hind templates. They were extracted during development from locally available DCS missions and unit data. The complete donor missions are not bundled.

Green Lantern overwrites identities, positions, tasks, routes and loadouts as defined in `../build.mjs`. Baseline settings and the OH-58D, Hornet and MiG records were previously read from personal Saved Games mission archives and a locally installed UH-60L quick-start mission. This project has no runtime dependency on those archives or the UH-60L mod.

The extracted configuration data is preserved for reproducible authoring. No redistribution license for donor mission content has been established. The owner has chosen to publish this collection publicly; this note records the remaining provenance limitation. Third-party mission art, audio and full scripts are not included here.
